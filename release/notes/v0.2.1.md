# Bonfim SDK 0.2.1

`0.2.1` is a pre-alpha hardening release focused on security boundaries, repository assurance, packaging and evidence-oriented release engineering.

## Highlights

- fail-closed handling for invalid workflow inputs and unexpected component failures;
- rollback behavior preserves step-specific inputs and records rollback failures explicitly;
- GitHub PR evidence, readiness, security and governance Skills;
- Python 3.11–3.14 validation matrix;
- coverage, Ruff, mypy, Bandit, full-history Gitleaks and CodeQL controls;
- CycloneDX SBOM generation;
- wheel and source-distribution verification;
- SHA-256 release-asset integrity evidence;
- build provenance attestation;
- protected-main rulesets and release governance;
- recruiter/developer-facing documentation and explicit threat model.

## Compatibility

This patch release does not intentionally remove a documented public API. See `docs/compatibility.md` for the current pre-1.0 compatibility and deprecation policy.

## Security boundary

Bonfim SDK remains a trusted in-process SDK. Allowlisted Python components execute with the privileges of the hosting process; the project does not claim sandboxing or isolation for arbitrary untrusted plugins.

## Distribution state

These notes are part of release-candidate preparation only. Their presence does **not** authorize a Git tag, GitHub Release, PyPI publication, production-readiness claim or removal of the pre-alpha designation.

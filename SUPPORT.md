# Support

Bonfim SDK is pre-alpha software intended for evaluation, learning and controlled development. It is not offered with an uptime, response-time or production-support commitment.

## Supported use

Reasonable support requests include:

- installation and CLI problems;
- reproducible SDK defects;
- documentation errors;
- compatibility issues on supported Python versions;
- questions about public interfaces and examples;
- proposals that preserve the documented trust and governance boundaries.

## Not supported

The project does not provide:

- legal, compliance or certification advice;
- production incident response;
- guarantees for third-party plugins;
- support for untrusted component execution;
- cloud, model-provider or connector operations;
- autonomous decision authority;
- review of private organizational data through public issues.

## Before requesting support

1. Confirm Python 3.11 or newer.
2. Run `bonfim doctor`.
3. Reproduce the issue in a clean virtual environment.
4. Run the documented test and validation commands.
5. Remove credentials, personal data and proprietary content.
6. Record the exact SDK version, operating system and minimal reproduction.

## Security issues

Do not use a normal issue for suspected vulnerabilities or sensitive findings. Follow [SECURITY.md](SECURITY.md).

## Maintenance policy

The current supported line is documented in [SECURITY.md](SECURITY.md). Pre-alpha interfaces may change. Breaking changes must be documented in `CHANGELOG.md` and use Semantic Versioning.

## Human authority

A support response, generated result or passing test does not authorize deployment, compliance claims, release or external action.

# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.2.x | Yes |
| 0.1.x | Security fixes only during the 0.2 adoption window |
| Earlier | No |

## Reporting

Do not disclose suspected vulnerabilities, credentials or exploit details in a public issue. Use GitHub private vulnerability reporting for this repository when available. If that feature is unavailable, contact a Bonfim Labs organization owner through a previously established private channel.

Preserve relevant evidence and provide the affected version, reproduction conditions, impact hypothesis and safe contact details. Receipt does not constitute confirmation of a vulnerability, compliance status or remediation deadline.

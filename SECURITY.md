# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.2.x | Yes |
| 0.1.x | Security fixes only during the 0.2 adoption window |
| Earlier | No |

## Reporting

Do not disclose suspected vulnerabilities, credentials or exploit details in a public issue.

Use GitHub private vulnerability reporting for this repository.

If private vulnerability reporting is temporarily unavailable, open a public issue titled `[Security] Private contact request` without including technical details, reproduction steps, credentials or exploit information. Wait until a private communication channel is established before sharing evidence.

Provide the affected version, reproduction conditions, impact hypothesis and safe contact details through the private report. Receipt does not constitute confirmation of a vulnerability, compliance status or a remediation deadline.
